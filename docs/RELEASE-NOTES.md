Volkspele 0.3.0 replaces reference book photos with typed content and lyric MIDI transcriptions. Each song is one standard MIDI download containing timed lyrics, all supplied verses, the available opening dance instructions and source notes.

Words, sheet music, steps, demonstrations and credits now open in accordion sections. History, clothing, contact and laer information expand inline, with downloads for offline reading. Rust handles HTTP, integrity, metadata, MIDI timing, lyric selection, synthesis and notation preparation. React and React Native render the results. Native mobile now displays generated lyric notation using a bundled offline renderer.

The current Pages library no longer publishes book photographs or directory screenshots. Full measure-by-measure dance instructions remain pending. The melody transcriptions need musical proofreading and omit piano accompaniment. Blinkvosperd's MIDI follows the printed score verse; its words section preserves all three separately supplied verses.

Launch update checks and hash-based content updates remain supported. Failed replacement downloads retain the prior saved file. App updates link to Releases for manual installation.

Windows, macOS and Linux have x64 and ARM64 installers. Android APK/AAB use the permanent signing key and support four ABIs. The iOS ZIP is an unsigned simulator build; physical iPhone installation requires Apple provisioning. Desktop installers are unsigned.
