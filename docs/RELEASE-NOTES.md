Volkspele 0.2.0 publishes the supplied history, clothing references, lyrics, original sheet photographs, dance introductions and a dated AVVB laer directory. The responsive website, native Android app and desktop apps download library files separately from their installers.

MIDI is the practice source. Rust handles parsing, timing, piano-like synthesis and notation preparation. Web and desktop display MusicXML notation, the original sheet and a piano roll; native mobile displays the original sheet and piano roll. Speed, repeat and offline playback are supported. These MIDI files are concept melody transcriptions awaiting musical proofreading, not complete piano arrangements. The original scores remain available for comparison.

App release checks start at launch, alongside the catalogue check. Changed content is detected by version and SHA-256 hash; a failed replacement retains the previous saved file. Updates link to Releases for manual installation. The production website can reopen offline after its first online visit.

Regression tests cover native UI rendering, browser screenshots at phone and desktop widths, downloads/cancellation/corrupt replacements, MIDI timing and playback, PDF pagination, offline saved content, production offline reload and update banners. Release publishing requires this suite to pass.

Windows, macOS and Linux have x64 and ARM64 installers. The signed universal Android APK supports ARM64, ARMv7, x86 and x86_64; the AAB is for store distribution. The iOS ZIP is an unsigned simulator build: physical iPhone installation requires Apple signing and provisioning. Desktop installers are not developer-signed or Apple notarized.

Demonstration videos open the supplied YouTube links and require internet. Full measure-by-measure dance instructions and additional promised photographs are still pending.
